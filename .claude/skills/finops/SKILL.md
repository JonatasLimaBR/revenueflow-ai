# GCP FinOps Skill

## Use when
Cost, scaling, BigQuery scans, Cloud Run sizing or AI token usage matters.

## Track
- Cloud Run cost/request;
- BigQuery bytes processed;
- Cloud SQL instance/storage;
- Pub/Sub throughput;
- Vertex AI token/model cost;
- AI Cost / Revenue Generated.

## Rules
Do not optimize by removing security, observability, backups or correctness controls.
