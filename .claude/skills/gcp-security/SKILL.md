# GCP Security Skill

## Use when
IAM, Secret Manager, PII, networking, agent tools or privileged operations are involved.

## Review areas
- service account privilege;
- secret exposure;
- public ingress;
- IAM bindings;
- cross-customer isolation;
- data retention;
- prompt injection;
- tool escalation;
- audit logging.

## Core principle
Security by architecture:
if an agent must not perform an action, do not register the tool for it.
