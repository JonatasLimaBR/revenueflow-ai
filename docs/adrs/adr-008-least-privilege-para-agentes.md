# ADR-008 — Least privilege para agentes

## Status
Accepted

## Contexto
Esta decisão faz parte da arquitetura do RevenueFlow AI e deve permanecer explícita para evitar implementação por acaso ou por preferência implícita.

## Decisão
Cada agente acessa somente as ferramentas necessárias.

## Alternativas consideradas
Todas as tools para todos os agentes.

## Motivo
Reduz risco de ações indevidas.

## Consequências
Exige gestão explícita de permissões.

## Regra de revisão
Alterações relevantes nesta decisão exigem novo ADR ou substituição formal deste documento.
