# ADR-018 — ML após histórico suficiente

## Status
Accepted

## Contexto
Esta decisão faz parte da arquitetura do RevenueFlow AI e deve permanecer explícita para evitar implementação por acaso ou por preferência implícita.

## Decisão
Adicionar ML para propensity, churn, CLV e next best action depois.

## Alternativas consideradas
Treinar modelos artificiais com dados frágeis.

## Motivo
Evita falso ganho de precisão.

## Consequências
Roadmap depende de coleta de dados.

## Regra de revisão
Alterações relevantes nesta decisão exigem novo ADR ou substituição formal deste documento.
