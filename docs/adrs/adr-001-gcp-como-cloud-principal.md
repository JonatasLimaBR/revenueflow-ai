# ADR-001 — GCP como cloud principal

## Status
Accepted

## Contexto
Esta decisão faz parte da arquitetura do RevenueFlow AI e deve permanecer explícita para evitar implementação por acaso ou por preferência implícita.

## Decisão
Usar Google Cloud como plataforma principal.

## Alternativas consideradas
Azure, AWS, Databricks integral.

## Motivo
Ambiente disponível, serviços serverless e integração forte com Vertex AI/BigQuery.

## Consequências
Maior dependência do ecossistema GCP.

## Regra de revisão
Alterações relevantes nesta decisão exigem novo ADR ou substituição formal deste documento.
