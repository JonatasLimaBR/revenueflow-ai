# PRD-011 — Venda Ativa via WhatsApp

## Objetivo
Permitir que oportunidades aprovadas iniciem jornadas comerciais outbound via WhatsApp.

## Fluxo
Opportunity → Policy Gate → Consent Check → Frequency Cap → Campaign Candidate → WhatsApp.

## Regras
O Opportunity Engine não envia mensagens diretamente.

## Métricas
- Mensagens autorizadas.
- Taxa de resposta.
- Conversão outbound.
- Opt-out rate.
