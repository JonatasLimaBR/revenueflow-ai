# PRD-012 — Arquitetura Multiagente

## Objetivo
Separar responsabilidades e permissões entre agentes especializados.

## Agentes V1
- Sales Supervisor
- Customer Agent
- Lead Agent
- Product Agent
- Inventory Agent
- Pricing Agent
- Negotiation Agent
- Opportunity Agent
- Order Agent

## Princípio
Least privilege por agente.

## Métricas
- Tool-call success.
- Handoffs.
- Erros por agente.
- Latência por workflow.
