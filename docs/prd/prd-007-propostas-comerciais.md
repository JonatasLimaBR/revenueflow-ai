# PRD-007 — Propostas Comerciais

## Objetivo
Gerar propostas comerciais rastreáveis e consistentes a partir de produtos, preços e políticas autorizadas.

## Escopo
- Itens.
- Quantidades.
- Preços.
- Descontos.
- Frete simulado.
- Total.
- Validade.
- Status da proposta.

## Status
DRAFT, PENDING_APPROVAL, APPROVED, SENT, ACCEPTED, REJECTED, EXPIRED.

## Métricas
- Propostas geradas.
- Quote Conversion Rate.
- Tempo até proposta.
