# PRD-010 — Opportunity Engine

## Objetivo
Detectar automaticamente oportunidades comerciais usando dados históricos.

## Tipos
- REPLENISHMENT
- CHURN
- REACTIVATION
- QUOTE_RECOVERY
- ORDER_RECOVERY
- CROSS_SELL
- UPSELL
- INVENTORY_TO_CASH

## Saída
Cada oportunidade deve possuir motivo, evidência, valor estimado, confiança e ação recomendada.

## Métricas
- Oportunidades detectadas.
- Valor potencial.
- Conversão por tipo.
- Receita incremental.
