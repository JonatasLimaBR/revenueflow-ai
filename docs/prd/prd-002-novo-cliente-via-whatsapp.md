# PRD-002 — Novo Cliente via WhatsApp

## Problema
Novos contatos chegam pelo WhatsApp sem saber exatamente qual produto precisam e sem cadastro no CRM.

## Objetivo
Converter um contato desconhecido em lead qualificado, proposta e pedido simulado.

## Jornada
WhatsApp → identificação → lead → qualificação → busca de produto → estoque → preço → proposta → cadastro → pedido → pagamento sandbox.

## Requisitos
- Criar lead automaticamente.
- Coletar dados mínimos de forma progressiva.
- Identificar intenção e necessidade.
- Recomendar apenas produtos presentes no catálogo autorizado.
- Registrar origem, interesse e status do lead.

## Métricas
- Leads criados.
- Leads qualificados.
- Conversão.
- Tempo até primeira proposta.
- Receita potencial.
