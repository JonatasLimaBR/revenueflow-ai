# PRD-014 — Segurança e Privacidade

## Objetivo
Proteger dados de clientes, credenciais e regras comerciais.

## Escopo
- IAM.
- Secret Manager.
- RBAC.
- Criptografia.
- PII minimization.
- Logs sem dados desnecessários.
- Tool permissions.
- Proteção contra prompt injection.

## Regra
Nenhuma mensagem do usuário altera políticas, permissões ou regras financeiras.
